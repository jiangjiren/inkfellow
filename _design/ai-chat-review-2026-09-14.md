## 确认并修复的问题

| 问题 | 原来的触发与影响 | 修复 |
| --- | --- | --- |
| 切模型/厂商丢上下文 | Codex 新建 thread、跨 SDK 切换没有补历史；切回旧厂商可恢复不完整的旧会话 | 以当前 conversation 为依据恢复 native session；配置变化时注入可迁移的双方文本和已保存的引用提示 |
| 全局会话串用 | 切历史/多标签页可能复用或打断不属于当前会话的 Claude 实例 | 记录 runtime 所属会话；Claude 前台忙时其他 Claude 会话排队；Codex 用本请求的 session ID |
| 第二轮提问回调指向第一轮 | 长驻 query 保留了第一次创建时的回调闭包 | 提问回调转发到当前 turn，并随当前 run 暂停/恢复计时器 |
| 停止/重置后等待不结束 | 丢掉 turn 指针却没 resolve/reject 原 Promise；每轮 abort 没绑定长驻 query | 取消操作只作用于所属 run，结清 Promise、关闭该 iterator，下一轮可以恢复 native session |
| 重连后提问卡消失 | 问题先推送，随后全量 sync 清掉卡片 | 先发同步结果，再重发待回答问题；运行状态参考仍存活的 run |
| 断线缓存继续增长 | 宽限期到期只清一次 buffer，后续事件仍追加 | 到期停止内存缓存，仍写事件日志；重连恢复缓存状态 |
| 历史加载乱序/失败清屏 | 连点历史时旧 GET 覆盖新选择；GET 失败仍渲染空摘要 | 导航版本校验；失败保留现有页面；新草稿使旧请求失效 |
| 全量快照后流式字消失 | 快照重画了 DOM，未恢复活跃 blockMap | 投影提供活跃流式块索引，浏览器恢复块状态后继续接收 delta |
| 停止后丢半截回复 | 只认完整 assistant 事件；done/stopped 清掉尚未保存的客户端缓冲 | 投影保存 provisional text/thinking，完整消息替换它；停止和同步结束时保存部分输出 |
| 历史消息 ID/标题错误 | 空失败轮次改写上一条 assistant ID；元数据更新不使投影缓存失效；自动保存覆盖重命名 | 只修改当前轮消息；元数据变更使缓存失效；显式重命名单独更新元数据 |
| 子任务内容混入主回复 | 投影将带 parent_tool_use_id 的 assistant 当主回复正文 | 子任务保留为运行事件，不合并到主回复正文 |
| 立即追加混合两轮 | 客户端沿用旧 assistant 状态，服务端沿用原请求 ID | 在追加边界结束旧回复并保留消息顺序；新轮绑定追加请求 ID |
| 排队/同步竞态 | 首条请求被排队后原 payload 未保留；同步完成前队列自动发送；旧 sync 重建新页面 | 保留原请求到队列；等待 sync；hello 加相关 ID；离屏 ACK 也完成传输确认 |
| 重启后重复执行 | 去重仅存内存，重启或缓存淘汰后同一消息可再执行工具 | 从持久化 turn 事件查询已处理请求；未完成的旧请求报告停止，不静默重新执行 |
| 删除会话后重新出现 | 计算继续向已删除的事件目录写入 | 删除前停止并丢弃该 run；删除失败不清理客户端状态 |
| SDK 失败被当成功 | Claude 用 result 事件返回错误却不抛异常；Codex 流缺少完成事件仍报 success | 统一检查 SDK 错误结果；Codex 必须收到完成确认 |
| 账号/权限变更影响错误会话 | 修改账号全局清 session；立即追加忽略新选权限/effort | 配置变更作用于后续请求；追加需匹配账号、模型、权限和 effort；旧账号 ID 显式报错 |
| 非法请求影响服务 | JSON null、数组、错误图片结构进入处理器可能抛异常 | 请求形状、ID、文字/图片结构校验；错误请求确认一次，避免无限重试 |
| Markdown 可执行 HTML | marked 结果直接写 innerHTML，可带事件处理器或脚本 URL | 使用固定版本 DOMPurify 清洗；不可用时回退纯文本；禁用会影响页面的 style/form 等标签 |
| 浏览器跨站操作 | WebSocket 和写接口不检查浏览器 Origin | 拒绝其他 hostname 的浏览器请求；保留同主机不同端口与可信本地代理的转发主机 |
| 微信连续消息历史覆盖 | 同一 sender 多轮并行读取同一历史、后完成者覆盖 | 从附件下载到回答保存按 sender 串行，其他 sender 独立执行 |
| 定时任务重复执行 | 上次尚未完成就到下一次触发时间 | 同一 job 执行期间跳过重入，结束后释放 |
| 间接依赖已知漏洞 | npm audit 报告 5 项生产依赖漏洞 | 定向更新相关间接依赖；复查为 0 项 |
